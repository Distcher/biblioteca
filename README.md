# Como usar essa aplicação
## Funcionamento do sistema:
Esse sistema foi baseado no aplicativo **Skeelo**, o funcionamente dele se resume em 4 etapas:
1. Usuario cadastra o livro
2. O sistema interpreta todas as informações, e se comunica com a API enviando todas as informações para o banco de dados, atualizando as informações no banco de dados. Todas as informações são editaveis **POR ENQUANTO**
